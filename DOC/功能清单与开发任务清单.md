## 二、功能清单

### A. 管理后台(apps/admin)—— 仅 IT 管理员
| 页面/模块 | 文件 | 功能 |
|---|---|---|
| 登录 | `views/LoginView.vue` + `stores/auth.ts` | 管理员登录、令牌存取/静默刷新 |
| 总览 | `views/OverviewView.vue` | 系统总览/指标 |
| 用户/部门管理 | `views/UsersView.vue` | 用户与部门增删改查(FE-W-04) |
| 空间治理 | `views/SpacesView.vue` | 空间列表/配额预警阈值 + 治理动作(FE-W-06) |
| 框架 | `layouts/AdminLayout.vue` + `router/index.ts` | 布局、路由守卫(权限/登录) |

> 能力边界(定稿):**不做任何在线预览**(看图/PDF/Office);文件浏览与传输在桌面客户端。

### C. 共享库(packages/)
- **`packages/api`**:`src/schema.gen.ts`(OpenAPI 自动生成类型,契约单源)+ `src/index.ts`(封装 fetch/DTO/令牌刷新——手写 fetch 必须收敛于此,由 lint-contract 机械门禁锁住)

### D. 工程门禁(scripts/)
- `lint-contract.mjs`:契约门禁(`check:api`)——①`packages/api` 之外禁止手写 fetch;②禁止手写与生成模型同名的 DTO;③`schema.gen.ts` 与 openapi 逐字节比对(双向 diff)
- `check-frontend-rules.mjs`(`check:rules`):7 条前端纪律(受众分端/令牌存储/守卫/静默刷新/入口顺序/受保护接口/平台 SDK),每条均有反向验证
- `gen-csharp.mjs`:桌面端 C# 模型生成钩子(拆分后归属调整,详见变更说明)

### E. 构建与脚本(package.json)
`build`/`build:admin`/`dev:admin`/`typecheck`/`lint`/`gen:api`/`gen:csharp`/`check:api`/`lint:contract`/`check:rules`
