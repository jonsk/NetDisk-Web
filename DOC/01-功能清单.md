# 功能清单

> 本仓库 = NetDisk 网盘的 **Web 前端（管理后台）**，Vue 3 + TypeScript + pnpm workspace。

## 仓库定位

| 项 | 内容 |
|---|---|
| 名称 | **web**（网盘前端 · 社区版） |
| 性质 | Vue 3 + TypeScript + pnpm workspace；单一构建目标 `admin` |
| 技术栈 | Vue 3 / Vite / Pinia / Naive UI / openapi-typescript |
| 消费者 | 产物经 `pnpm build` 拷入服务端 `internal/webui/dist/`，由 Go `embed` 提供 |
| 契约 | 本仓 vendor 一份 `DOC/api/openapi.yaml`（权威源 `Doc/api/openapi.yaml`） |

**子目录**：`apps/admin`、`packages/api`、`scripts`、`DOC`。

---

## A. 管理后台（`apps/admin`）—— 仅 IT 管理员

| 页面/模块 | 文件 | 功能 |
|---|---|---|
| 登录 | `views/LoginView.vue` + `stores/auth.ts` | 管理员登录、令牌存取/静默刷新 |
| 概览 | `views/OverviewView.vue` | 当前会话信息（用户/角色/受众/request_id） |
| 用户与部门 | `views/UsersView.vue` | 用户与部门增删改查、停用/启用、角色调整、二次确认 |
| 空间治理 | `views/SpacesView.vue` | 空间列表、配额/预警阈值、冻结、收回 |
| 框架 | `layouts/AdminLayout.vue` + `router/index.ts` | 布局、路由守卫（登录/鉴权/原地址） |

> **能力边界（定稿）**：不做任何在线预览（看图 / PDF / Office）；文件浏览与传输
> 在桌面客户端。Web 后台只做**全局治理**，新建空间/邀请成员等协作管理入口在
> 桌面端。

### 各页面细节

- **登录**：`audience: "web"` 显式传参（分端受众），令牌存 `sessionStorage`，
  登录失败统一文案（不区分"用户不存在/密码错误"），429 单独提示。
- **概览**：仅显示当前登录者信息，刻意不堆假数据图表。
- **用户与部门**：服务端搜索/分页（非前端过滤）、停用二次确认（有外部影响）、
  唯一冲突错误落到具体输入框、部门树增删。
- **空间治理**：用量只读（只由上传/删除事务增减）、预警阈值是"提醒线"而非上限
  （上限 95% 由服务端硬策略）、**收回≠删除**（冻结+清空成员，文件不删）。

## B. 共享库（`packages/`）

- **`packages/api`**：
  - `src/schema.gen.ts` —— OpenAPI 自动生成类型（契约单源，**禁手改**）；
  - `src/index.ts` —— 类型化 REST 客户端封装（fetch/DTO/令牌注入/静默刷新，
    唯一允许出现 `fetch(` 的地方）。

---

## C. 工程门禁（`scripts/`）

- **`lint-contract.mjs`**（`check:api` / `lint:contract`）：契约门禁——约束手写
  fetch、手写同名 DTO、生成物过期三类失血点（细节见 06-测试文档「契约门禁」）。
- **`check-frontend-rules.mjs`**（`check:rules`）：前端纪律 7 条（R1~R7），
  每条均有反向验证（细节见 06-测试文档「前端纪律」）。
- **`gen-csharp.mjs`**：桌面端 C# 模型生成钩子（`desktop/` 不存在时仅校验链路、退出 0）。
