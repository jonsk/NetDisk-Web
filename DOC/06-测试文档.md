# 测试文档

> 本仓库**未引入浏览器测试运行器**。作为替代，把**能被文本判定的纪律**做成零依赖
> 静态门禁，可在 CI 直接跑、且每条都能"破坏即红"。门禁**不能**替代人工验收
> （交互、样式、真机），需两者互补。

## 一、自动化门禁总览

| 门禁 | 命令 | 做什么 |
|---|---|---|
| 契约一致性 | `pnpm check:api` | 生成物与 `openapi.yaml` 双向 diff + 手写 fetch/DTO lint |
| 契约 lint | `pnpm lint:contract` | 同上的 lint 部分 |
| 类型检查 | `pnpm -r typecheck` | vue-tsc / tsc 严格模式全仓类型检查 |
| 前端纪律 | `pnpm check:rules` | 7 条纪律静态检查 |
| 构建 | `pnpm build` | 编译产物 + 校验 `dist/index.html` 存在 |

**CI 顺序**（`.github/workflows/ci.yml`）：
`install(frozen) → check:api → typecheck → check:rules → build →`
产物校验。

## 二、契约门禁（`check:api` / `lint:contract`）

脚本 `scripts/lint-contract.mjs`，防三类"契约单源被悄悄破坏"：

1. **手写 fetch**：`packages/api` 之外出现 `fetch(` 即失败 —— 请求必须收敛到
   客户端，保证类型/错误/刷新一份实现。
2. **手写同名 DTO**：`packages/api` 内不得 `interface/type` 与生成模型同名
   （应写 `export type X = Schema["X"]`，随契约变化）。
3. **生成物过期**（`--check-generated`）：重新生成后与提交物逐字节比对，不一致
   说明改了契约没重新生成、或手改了生成物。

通过输出：`契约门禁通过:fetch 已收敛、无手写 DTO、生成物与契约一致`。

## 三、前端纪律（`check:rules`）

脚本 `scripts/check-frontend-rules.mjs`，7 条纪律，每条只钉"写错不报错、只会
**静默做错事**"的地方：

| 规则 | 检查点 | 破坏后果 |
|---|---|---|
| R1 | admin 登录带 `audience="web"` | 登录成功但接口全 403 |
| R2 | 令牌只存 sessionStorage（禁 localStorage） | 共用电脑长期留存管理凭据 |
| R3 | 守卫未登录跳登录页且保留原地址（redirect） | 登录后被送回首页，丢原页面 |
| R4 | 401 静默刷新并**重放一次**（doFetch 两次） | 只刷新不重放 = 仍然失败 |
| R5 | 入口先 `auth.restore()` 再挂路由 | 每次刷新被弹回登录页 |
| R6 | 受保护 API 不得 `href/window.open` 直接打开 | 不带令牌 401 / 令牌进浏览器历史 |
| R7 | 后台不得直接用平台 SDK 全局（wx/dd） | 依赖平台注入对象、非纯 Web |

实现细节：判定前先 `stripComments` 剥掉注释（避免注释里的示例字符串误报），
每条都带反向验证（存在性 + 语义双重检查）。

通过输出：`全部通过:7 条前端纪律。`

## 四、首页验证（`gen:csharp`）

桌面端 C# 模型生成钩子 `scripts/gen-csharp.mjs`：
- 永远解析契约并做完整映射（链路持续被真实契约验证）；
- `desktop/` 不存在时打印跳过原因并**退出 0**（不因桌面端缺席而红）；
- 存在时写 `Generated/Models.g.cs` 并逐字节比对（可用于 CI）。

## 五、人工验收清单

门禁覆盖不到、需人工核对的部分：

- **登录闭环**：登录 → 概览；登出 → 回登录页；刷新页面不被弹回。
- **令牌过期静默刷新**：手动让 access token 过期，验证 401 自动刷新+重放、
  无感恢复。
- **守卫行为**：未登录访问受保护路由 → 重定向登录且带原地址，登录后回原页。
- **用户/部门**：建号、改角色、停用（二次确认）、唯一冲突错误落到输入框、
  服务端搜索分页。
- **空间治理**：配额/预警阈值保存、冻结/解冻、收回（提示文件不删）、
  用量只读不可手改。
- **429 限速**：登录失败过频提示"请稍后再试"。
- **真机/浏览器 × 分辨率**：桌面浏览器为主，兼顾较老内核。

> 交互、样式、真机表现属于门禁盲区，务必在合并前人工过一遍「人工验收清单」。
